前往我的 GitHub
iPhone 插件和普通 App 有什么区别？

Duo、NativeAlbumFilter 和 PhotosVideo2x 在系统界面或原生相册中工作，需要匹配的越狱与插件注入环境。它们使用 DEB 插件包，不是直接从 App Store 安装的普通应用。安装前请核对各项目说明中的系统、架构与越狱环境要求。

Venera-Max 可以在哪些设备上使用？

Venera-Max 支持 iOS 与 Android。Android 使用 APK 安装；iOS 使用 IPA，按项目文档配置签名与安装方式。内容源的配置和支持情况以项目说明为准。

在哪里获取安装包和更新？

在项目详情中选择「查看发布版本」，或进入 GitHub 仓库查看 README 和 Releases。若暂未公开发布安装包，请遵循仓库中的构建或获取说明。网站入口会指向项目页面，版本信息以仓库为准。

遇到问题，怎么反馈更有效？

通过项目的 GitHub Issues 提交反馈。附上设备型号、系统版本、项目版本、越狱环境（如适用）和复现步骤；截图或日志中请遮盖个人内容。详细的信息有助于定位问题。
